# 👋 Welcome to the HR Sheets resource library.

## Practical Excel resources built for HR professionals

This is where you'll find downloadable Excel resources designed to help HR professionals build practical Excel skills using realistic workplace scenarios.

# 🚀 About HR Sheets

HR Sheets helps HR professionals learn Excel using HR specific examples and case studies.

Instead of learning Excel through generic examples, HR Sheets focuses on the types of tasks HR professionals actually do:

- Working with employee data
- Building HR reports
- Cleaning spreadsheets
- Using formulas more effectively
- Reducing repetitive manual work

---

# ⚠️ Disclaimer

All employee names, information, and examples are fictional and created for educational purposes.

These resources are designed to help you learn Excel skills. Always review and validate formulas, calculations, and processes before using them in a workplace environment.
